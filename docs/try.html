Try plat2json in your browser

Drop one vector plat PDF and get plan-JSON and a DXF back. It all runs in this tab.

Rough geometry skeleton, not survey-grade. This reads the PDF’s own vector paths and text layer. It does not check closure, fix bad linework, or vouch for any bearing. Want a checked DWG? plat2cad.

This looks like a scanned plat

Scanned plats have no vector linework or text layer to read. They need the vision reader, which runs a local model on a GPU and can’t run in a browser. Nothing was sent anywhere.

Open a prefilled email

Attach the PDF yourself. A mailto link can’t attach files, so the email opens without it.

Once you send it, the plat is queued for the vision path. There is no set turnaround.

Your PDF never leaves this tab: no upload, no analytics, nothing kept. The page loads Pyodide (Python in WebAssembly) and PyMuPDF from the jsDelivr CDN, and ezdxf from PyPI. vector_plan.py and plan2dxf.py are served with this page. The first run downloads about 22 MB. See also the plat reader demo.
